# Bitcoin Market Sentiment vs Trader Performance Analysis

## Overview
This project explores the relationship between Bitcoin Fear & Greed Index and trader performance using Hyperliquid historical trading data.

## Objectives
- Analyze trader behavior across market sentiments
- Study profitability trends
- Identify profitable trading patterns
- Generate actionable trading insights

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Project Workflow
1. Data Cleaning
2. Feature Engineering
3. Dataset Merging
4. Exploratory Data Analysis
5. Statistical Testing
6. Business Insights

## Key Findings
- Profitability varies across different market sentiments.
- Win rate changes with market psychology.
- Trade size and fees influence overall returns.
- Top-performing traders show consistent trading behavior.
